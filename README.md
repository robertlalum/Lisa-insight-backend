# L.I.S.A. Insight – Real-Time AI Negotiation Assistant

L.I.S.A. Insight is a real-time AI assistant designed to help you during live conversations — whether in person, on Zoom, or in meetings. Think of it as a whispering AI in your ear that helps you stay sharp, ask the right questions, and avoid making mistakes during important discussions.

## 💡 What it Does

- Listens to your live conversation
- Transcribes what’s being said (using OpenAI Whisper)
- Analyzes it with AI (using GPT-4o)
- Gives you strategic advice in real-time (whispered or displayed)

## 🧠 Example Use Cases

- Business negotiations
- Interviews
- Investor or sales calls
- Strategy meetings
- Anytime you need to think faster under pressure

## 🚀 Current Status

This is an early prototype focused on setting up the backend API using Python Flask. More features will be added soon, including:
- Real-time speech input
- Integration with OpenAI models
- Smart tips and decision suggestions
- Emotion & intent detection

## 🛠️ Tech Stack

- Python (Flask)
- OpenAI Whisper (speech-to-text)
- OpenAI GPT-4o (AI assistant)
- Railway (cloud deployment)
